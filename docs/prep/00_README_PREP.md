## אילוצים שאומתו בקוד (ולא הוסקו)
1. **אין `package-lock.json` באף ריפו**, ו-`playwright` צף (`^1.55.0` ב-Green, `^1.49.0` ב-Gold). לכן גרסת Chromium משתנה בין ריצות. זה משפיע ישירות על החלטה 4 ועל דטרמיניזם.
2. **ה-CLI של Green אינו רושם גרסת דפדפן** בדוח.
3. **ה-CLI של Green דורש decision-ledger.** במנוע Gold יש 0 הפניות ל-`data-layout-decision-record`, ולכן השער `instrumentationIntegrityFailures` ייכשל עליו.
4. **שני מימושים נפרדים של אבחון step-by-step ב-`geometry-audit.js`** מתנגשים באותו מקום: hunk 8 מכיל 506 שורות מצד Green מול 731 מצד Gold.
5. **העברת קומיטים פר-קומיט אינה מעשית**: 37 מתוך 46 הקומיטים עם קוד מתנגשים (1–11 hunks).
6. **אותן תכונות מומשו פעמיים:** כותרות זוגי/אי-זוגי ועיטורי H2 (hunks 1–4 ב-`buildHeaderGridHTML`).
